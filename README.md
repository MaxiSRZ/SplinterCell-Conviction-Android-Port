## About

An unofficial Android port of the classic
Tom Clancy's Splinter Cell: Conviction mobile game,
originally developed by Gameloft.

Ported by **MazathStudios** with the goal of preserving
classic mobile gaming on modern Android devices.

## ✨ Features

- Standalone Android application.
- No external emulator required.
- Enhanced Android compatibility.
- Touchscreen controls.
- Fullscreen landscape gameplay.
- Original gameplay preserved.
- Free to play.
- Signed with the MazathStudios certificate.

## 📱 Compatibility

- Android 5.0 and newer.
- Successfully tested on Android 16.
- No additional emulator required.
